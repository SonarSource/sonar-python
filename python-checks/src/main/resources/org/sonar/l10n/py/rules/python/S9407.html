This rule raises an issue when a for loop only yields each element of an iterable and could be replaced by a yield from statement.

Why is this an issue?

Introduced by PEP 380, the yield from statement delegates the iteration of a generator to a sub-iterable.

def generator():
    yield from range(10)

Rewriting a for loop whose body is a single yield of the loop variable into yield from has several benefits:

  • It states the intent directly: the generator delegates to another iterable instead of manually relaying its values.
  • It removes a loop variable that serves no other purpose.
  • It is faster, because the values are relayed by the interpreter instead of going through a Python-level loop.
  • It forwards send(), throw() and close() calls to the sub-generator, and makes its return value available, which a manual loop silently discards.

How to fix it

Replace the for loop with a yield from statement over the same iterable.

Code examples

Noncompliant code example

def read_files(paths):
    for path in paths:
        with open(path) as file:
            for line in file:  # Noncompliant: this loop only relays the lines of the file
                yield line

Compliant solution

def read_files(paths):
    for path in paths:
        with open(path) as file:
            yield from file

Pitfalls

yield from is not allowed in asynchronous generators. An async for loop that yields each element cannot be rewritten this way, and this rule does not raise an issue on such loops.

async def relay(async_iterable):
    async for value in async_iterable:
        yield value

The two forms are equivalent as long as the sub-iterable is only iterated over. They diverge when it is a generator that the caller drives with send() or throw(): the manual loop keeps those calls for itself, while yield from passes them on to the sub-generator. The sub-generator’s return value also becomes the value of the yield from expression instead of being discarded. Check how the sub-iterable is consumed before rewriting a loop that delegates to a generator.
